Treat it exactly as you would a user's own pile. Do not assume anything about it beyond what the files say.
3. Name the project `atlas-test`. Before you start, tell the user in one or two sentences what is in the package. Mention that it was written by a person, independently of the tool, as a realistic test.
4. When you hand over, end by telling the user they can run the same thing on their own material by attaching files and asking for a first-draft deck.
